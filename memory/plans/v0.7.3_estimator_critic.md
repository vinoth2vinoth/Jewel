# Design Plan: Jewel v0.7.3 - Test Correctness Critic and Scope Preflight

We will enhance Jewel's capabilities to detect reasoning/logic errors in generated test cases and dynamically adjust scope budgets before LLM patch proposal execution.

---

## 1. Objectives

- **Feature 1: Preflight Scope Estimator**: Before calling the patch proposal agent, check if the LLM's planned task contract expects file/line changes exceeding the user's config budgets. Prompt the user for a scope expansion if exceeded.
- **Feature 2: Generated-Test Critic**: A dedicated critic endpoint to review test correctness when verification fails, evaluating whether the error resides in the test logic or the implementation.
- **Feature 3: Domain Rule checks**: Direct the critic prompt to check domain specific logic (e.g., matrix dimension compatibility, boundary behaviors).
- **Feature 4: Automated Self-Fixing Retry Loop**: When verification fails in agent mode, feed the test runner's exact failure output and critic feedback back to the patch proposer to automatically generate a corrected patch, up to `maxRetries` times.
- **Feature 5: Detailed Failure Statuses**: Support new statuses `VERIFICATION_FAILED_DUE_TO_TEST_LOGIC` and `GENERATED_TEST_SUSPECT` (or `BAD_GENERATED_TEST`) to distinguish test code logic issues.
