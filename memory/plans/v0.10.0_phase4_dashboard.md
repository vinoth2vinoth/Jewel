# Design Plan: Jewel v0.10.0 Phase 4 - Premium Dashboard Visual Enhancements

This design plan outlines the implementation of Phase 4 of the Jewel v0.10.0 roadmap: **Premium Dashboard Visual Enhancements**.

---

## 1. Objectives & Features

1. **Interactive AST Tree Differences**
   - Extend the AST diffing engine to collect and structure signature additions and deletions.
   - Build an interactive, collapsible tree component in the Web UI using `<details>` and `<summary>` elements to visualize structural changes.

2. **Selective Patch Checklist**
   - Provide checkbox controls for each modified file in the patch review modal.
   - When files are unchecked, dynamically filter the displayed unified diff to show only the remaining changes.
   - Upon clicking "Approve & Apply", send the list of selected files back to the CLI server, and programmatically revert the unselected files to their checkpoint/backup state before proceeding.

3. **API Cost Gauge**
   - Add a circular meter (SVG-based gauge) in the dashboard sidebar showing cumulative session dollar cost relative to `config.maxSessionCost`.
   - Update and broadcast real-time prompt/completion tokens and total USD cost estimates to the UI server.

---

## 2. Affected Files

1. `src/safety/diff-guard.ts`
   - Extend `DiffAnalysis` interface to include `astDiffs`.
   - Update `runASTDiffAnalysis` to compare signatures in both directions (extracting both deleted/modified signatures and added signatures).
   - Ensure `runASTDiffAnalysis` always runs to compile the AST differences if `useUI` or human approval is enabled (even if `useASTDiffGuard` is false, in which case we only warnings but do not block validation).

2. `src/storage/git.ts`
   - Define and export `revertFileToCheckpoint(file, checkpoint, cwd)` helper.
   - Guard against pathspec crash: if a file did not exist in the checkpoint commit, delete it from disk and unstage/remove it from Git tracking.

3. `src/cli/ui-server.ts`
   - Extend `UIState` and `approvalDetails` interfaces to include `astDiffs`, selective file lists, and cost metrics.
   - Update `approvalResolver` and `waitForApproval` signatures to support passing `approvedFiles`.
   - Update `POST /api/action` body parsing to support passing `approvedFiles` through the `approvalResolver`.

4. `src/cli/commands/run.ts`
   - Import `revertFileToCheckpoint` from `../../storage/git`.
   - Add token usage/cost updates (mapped from adapter names) to `uiServer` state updates after planning and patch proposals.
   - Update the patch review block to handle approvals and rejections for both UI and CLI prompts correctly, setting `approved = false` on reject, and reverting rejected files if approved.

5. `src/cli/dashboard-html.ts`
   - Add glassmorphic visual styling and SVG paths for the Circular Cost Gauge.
   - Implement division-by-zero check for `maxSessionCost` in the frontend gauge.
   - Render the collapsible AST signature tree explorer in the review modal.
   - Implement unified diff parsing by file header (`diff --git`) in front-end JS to support showing/hiding diffs based on checkbox checklist state.
   - Send `approvedFiles` array to the API action endpoint on approval.

```typescript
// Inside the per-file loop:
const items: ASTDiffItem[] = [];
for (const sig of oldSignatures) {
  if (!newSignatures.has(sig)) {
    const isAllowed = allowedSymbolChanges.some(allowed => { ... });
    if (!isAllowed) {
      findings.push(`AST Diff Guard: Deleted or modified signature of '${sig}' in '${file}'.`);
      status = 'BLOCK';

    items.push({ type: 'deleted', signature: sig });

}
for (const sig of newSignatures) {
  if (!oldSignatures.has(sig)) {
    items.push({ type: 'added', signature: sig });

  astDiffs.push({ file, items });
}
// At end of function:
return { status, findings, astDiffs };
```

### B. Safe File Reversion (`src/storage/git.ts`)
```typescript
export function revertFileToCheckpoint(file: string, checkpoint: CheckpointMetadata, cwd: string = process.cwd()): void {
  const absolutePath = path.resolve(cwd, file);
  if (checkpoint.isGit && checkpoint.gitCheckpointSha) {
    try {
      // Check if file existed in checkpoint commit
      let fileExisted = false;
      try {
        execSync(`git show ${checkpoint.gitCheckpointSha}:"${file}"`, { cwd, stdio: 'ignore' });
        fileExisted = true;
      } catch {}

      if (fileExisted) {
        execSync(`git checkout ${checkpoint.gitCheckpointSha} -- "${file}"`, { cwd, stdio: 'ignore' });
      } else {
        // Did not exist - delete from disk
        if (fs.existsSync(absolutePath)) {
          fs.unlinkSync(absolutePath);
        }
        // Remove from git index
        try {
          execSync(`git rm --cached -f "${file}"`, { cwd, stdio: 'ignore' });
        } catch {}
      }
    } catch (err: any) {
      console.warn(`[Warning] Failed to revert file ${file} via Git: ${err.message}`);
    }
  } else if (checkpoint.backupPath) {
    const backupFilePath = path.join(checkpoint.backupPath, file);
    if (fs.existsSync(backupFilePath)) {
      try {
        // Ensure parent directory exists for deeply nested files
        fs.mkdirSync(path.dirname(absolutePath), { recursive: true });
        fs.copyFileSync(backupFilePath, absolutePath);
      } catch (err: any) {
        console.warn(`[Warning] Failed to restore backup for ${file}: ${err.message}`);
      }
    } else {
      try {
        if (fs.existsSync(absolutePath)) {
          fs.unlinkSync(absolutePath);
        }
      } catch (err: any) {
        console.warn(`[Warning] Failed to delete temporary file ${file}: ${err.message}`);
      }
    }
  }
}
```

```typescript
let approvedFiles: string[] = [];

      approved = false;

      approved = false;
    }
```

### E. Frontend Enhancements (`src/cli/dashboard-html.ts`)
1. **Circular Cost Gauge**: Implement SVG gauge, displaying `totalUSD` as ring fill percentage. Check `maxCost > 0` before computing percent. If zero, render "No Limit" and 0%.
2. **AST Tree Diff Explorer**: Collapsible details/summary block with signature colors (`added` vs `deleted`). **XSS Safety**: Use `textContent` (not `innerHTML`) when inserting signature strings to prevent injection from source code containing HTML-like characters (e.g., `Array<string>`).
3. **Selective Patch Checklist**: Render files as checklist. On click, parse/split diff string by file headers (`diff --git a/... b/...`) and hide non-selected file blocks. **Non-git fallback**: If `diff` is empty or contains the non-git backup message, disable file-level filtering and show a "Full workspace restore only" message instead. On approval, submit checkbox state as `approvedFiles` POST payload.
