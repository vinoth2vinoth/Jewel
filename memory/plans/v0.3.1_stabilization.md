# Plan - Jewel v0.3.1: Stabilization

This plan outlines the steps to stabilize the LLM adapter foundation, bump the package version to 0.3.0, restrict forbidden execution fields directly in validators, validate empty patches, add OpenAI mock integration testing, improve secret redaction tests, and update documentation.

## Affected Files
1. `package.json`
2. `package-lock.json`
3. `src/agents/adapter.ts`
4. `src/agents/providers/openai-adapter.ts`
5. `src/agents/json-response.ts`
6. `src/agents/json-response.test.ts`
7. `src/cli/commands/run.ts`
8. `src/safety/secret-redactor.ts`
9. `src/safety/secret-redactor.test.ts`
10. `README.md`

## Expected Changes
1. **Version Bump**:
   - Update `version` in `package.json` and `package-lock.json` to `"0.3.0"`.
2. **Clarify OpenAI Adapter**:
   - Rename comments/labels in `src/agents/providers/openai-adapter.ts` to clearly state "OpenAI Chat Completions adapter".
   - Update `README.md` with Chat Completions usage and Responses API roadmap notes.
3. **Forbidden Execution Validation in JSON response**:
   - Add `assertNoForbiddenExecutionFields(input: unknown): void` in `src/agents/json-response.ts` to recursively block:
     - `command`, `commands`, `shell`, `terminal`, `run`, `runs`, `exec`, `execute`, `script`, `scripts`, `tool`, `tools`, `function_call`, `tool_calls`.
   - Call this validator in `validateTaskContractJson`, `validatePatchProposalJson`, and `validateReviewResultJson`.
   - Update `src/agents/json-response.test.ts` with test cases for these blocks.
4. **Prevent Empty Patch Success**:
   - Extend `PatchProposal` schema with optional `noChangeNeeded?: boolean` and `noChangeReason?: string`.
   - If files array is empty, `noChangeNeeded` must be `true` and `noChangeReason` must be a non-empty string.
   - Update `jewel run` in `src/cli/commands/run.ts` to report `NO_CHANGES_DETECTED` status and md/json reports if `noChangeNeeded` is true, otherwise block/fail if files array is empty.
5. **Add OpenAI Run-Level Mocked Integration Test**:
   - Create `src/cli/commands/run.openai.test.ts` or add to `run.test.ts` to mock OpenAI completions and verify `jewel run --mock` integration with provider configured to openai.
6. **Improve Secret Redactor Tests**:
   - Update `src/safety/secret-redactor.test.ts` to cover exact env vars, sk- keys, GitHub tokens (ghp_ and github_pat_), private key block, .env style secrets, Authorization Bearer token, and x-api-key headers.
7. **Documentation**:
   - Add "Using real LLM providers safely" warning section to `README.md`.

## Verification

2. Run `npm test`
3. Run `node dist/cli/index.js --help`
4. Run `npm pack --dry-run`
