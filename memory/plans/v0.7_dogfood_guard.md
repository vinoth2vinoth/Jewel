# Plan - Jewel v0.7: Dogfood Fixture Guard and Release Check Update

This design plan details the steps to restore the dogfood project to a broken state, create a validation script, integrate it with `jewel release-check`, and write tests verifying this behavior.

## Affected Files
1. `examples/dogfood-broken-project/src/math.ts` (Broken initial state)
2. `scripts/verify-dogfood-fixture.js` (New script to assert dogfood fixture is broken)
3. `package.json` (Add script `"verify:dogfood-fixture"`)
4. `src/cli/commands/release-check.ts` (Add check for dogfood fixture broken status)
5. `src/cli/commands/release-check.test.ts` (Add test coverage for dogfood fixture checks)

## Implementation Strategy

### Phase 1: Restore Broken State
- Revert `examples/dogfood-broken-project/src/math.ts` to not check for `b === 0` in `divide`.

### Phase 2: Manual Workflows Verify
- Confirm `npm test` fails initially in `examples/dogfood-broken-project`.
- Run Jewel mock fix and verify it successfully updates the file and passes tests.
- Confirm tests pass post-fix.

### Phase 3: Automated Dogfood Fixture Guard Script
- Implement `scripts/verify-dogfood-fixture.js`:
  - Run `npm run build` or similar compilation for dogfood project.
  - Run `npm test` inside `examples/dogfood-broken-project` and expect a non-zero exit code (failure).
  - If it succeeds, exit with non-zero (indicating the fixture is not broken).
  - Add `"verify:dogfood-fixture": "node scripts/verify-dogfood-fixture.js"` to `package.json`.

### Phase 4: Update `release-check`
- In `src/cli/commands/release-check.ts`, invoke the dogfood verification script.
- If it exits with failure, report `[WARN]` or `[FAIL]`/`[PASS]` accordingly (specifically `[FAIL]` if it passes/is fixed, `[PASS]` if it fails/is broken as expected).

### Phase 5: Test Coverage
- In `src/cli/commands/release-check.test.ts`, add unit tests checking both when the fixture is broken (accepted) and when the fixture is fixed (rejected).

### Phase 6: Final Verification
- Run tests and reset the fixture to broken state in git before final commit.
