# Design Plan: Jewel v0.8.0 Release Prep

Prepare the codebase for the official v0.8.0 release.

## Affected Files
1. **`package.json`**: Update version string to `0.8.0`.

## Steps
1. Modify `version` key in `package.json` to `"0.8.0"`.
2. Run `npm run build` to compile the TypeScript files (so compiled files capture the new version info).
3. Run `npm test` to ensure all tests pass.
4. Run `node dist/cli/index.js release-check` to verify readiness (checking credentials leakage, file list packaging config, etc.).
5. Run `npm run verify:dogfood-fixture` to verify the local dogfood example.
6. Commit the version bump changes.
