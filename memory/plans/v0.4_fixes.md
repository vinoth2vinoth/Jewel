# Plan - Jewel v0.4 Fixes & Acceptance

This plan outlines the fixes needed to resolve v0.4 validation issues, including incomplete test running, dogfood mock failure, dogfood package script configuration, version bump to `0.4.0`, and run-level integration tests for Gemini, Anthropic, and OpenRouter.

## Affected Files
1. `package.json` (Bump version, update test script)
2. `package-lock.json` (Bump version)
3. `scripts/run-all-tests.js` (New Node script to recursively run all tests in `dist/**/*.test.js`)
4. `src/agents/adapter.ts` (`MockAgentAdapter.plan` and `proposePatch` updates)
5. `examples/dogfood-broken-project/package.json` (Update test script to build first)
6. `src/cli/commands/run.test.ts` (Add run-level integration tests for Gemini, Anthropic, and OpenRouter)

## Problem Details & Solutions

### Problem 1: npm test does not run all tests
- **Solution**: Create a script `scripts/run-all-tests.js` that recursively searches `dist/` for any file matching `**/*.test.js` and runs them using `node --test`.
- Update `package.json`'s `"test"` script to `"node scripts/run-all-tests.js"`.
- Ensure it works across Windows, macOS, and Linux without shell glob expansion, exiting with a non-zero code if any test fails.

### Problem 2: Dogfood mock demo does not work
- **Root Cause**: `MockAgentAdapter.plan` returns a contract that always sets `filesLikelyNeeded: ['src/index.ts']` instead of respecting the user-declared files.
- **Solution**: Update `MockAgentAdapter.plan` to respect the `filesNeeded` from `PlanInput` if available (e.g. `input.config` or pass the cli options, or just use the files list from the session task description or the plan inputs). Wait, let's look at `PlanInput`. It has `PlanInput.task`, `PlanInput.repoSummary`, `PlanInput.config`, `PlanInput.skills`, `PlanInput.sessionPath`.
- Wait! Let's check `src/cli/commands/run.ts` to see what is passed to `adapter.plan`.
  In `run.ts`:
  ```typescript
      contractFromAdapter = await adapter.plan({
        task,
        repoSummary,
        config,
        skills,
        sessionPath
      });
  ```
  Ah! It does not pass `filesNeeded` in the arguments!
  But wait! `runTask` signature has `filesNeeded: string[]`. We can add `filesNeeded?: string[]` to `PlanInput` and pass it from `runTask`!
  Let's check `src/agents/adapter.ts` for `PlanInput`. Yes:
  ```typescript
  export interface PlanInput {
    task: string;
    repoSummary: string;
    config: JewelConfig;
    skills: Skill[];
    sessionPath?: string;
    filesNeeded?: string[]; // Add this!
  }
  ```
  Then in `run.ts` pass `filesNeeded` to `adapter.plan({ ..., filesNeeded })`.
  And inside `MockAgentAdapter.plan(input: PlanInput)`:
  ```typescript
    const files = input.filesNeeded && input.filesNeeded.length > 0 ? input.filesNeeded : ['src/index.ts'];
    const contract = generateLocalContract(input.task, input.config, files);
  ```
  This is incredibly clean and directly solves the issue!
- Also update `MockAgentAdapter.proposePatch` to support:
  - If a file ends with `math.ts`, write TypeScript math implementation:
    ```typescript
    export function add(a: number, b: number): number {
      return a + b;
    }

    export function divide(a: number, b: number): number {
      if (b === 0) {
        throw new Error("Cannot divide by zero");
      }
      return a / b;
    }
    ```
  - If a file ends with `math.js`, write CommonJS math implementation.
  - Otherwise use current mock content.

### Problem 3: Dogfood npm test alone is misleading
- Update `examples/dogfood-broken-project/package.json`:
  ```json
  "scripts": {
    "pretest": "npm run build",
    "test": "node --test dist/*.test.js"
  }
  ```
  This guarantees a fresh build runs before testing, preventing misleading passes/skips.

### Problem 4: Version number still 0.3.0
- Bump `version` to `"0.4.0"` in `package.json` and `package-lock.json`.

### Problem 5: Add run-level tests for all providers
- Add run-level mocked tests in `src/cli/commands/run.test.ts` for Gemini, Anthropic, and OpenRouter, asserting safe patches write correctly and unsafe parent traversals are blocked.
