# Jewel VS Code Extension (Scaffold)

Minimal extension that shells out to the `jewel` CLI in an integrated terminal.

## Commands

- **Jewel: Run Task** — prompts for a task and runs `jewel run "<task>" --yes`
- **Jewel: Verify** — runs `jewel verify`
- **Jewel: Status** — runs `jewel status`

## Install (development)

1. Install [Jewel CLI](https://www.npmjs.com/package/jewel-cli) globally or ensure `jewel` is on PATH.
2. Open this folder in VS Code and press F5 to launch an Extension Development Host.
